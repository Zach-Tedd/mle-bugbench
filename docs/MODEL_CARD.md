# Model card

- **Model:** architecture, parameter count, framework and version
- **Intended use:** what it is for, and what it must not be used for
- **Training data:** see DATA_CARD.md
- **Evaluation:** metric, split, threshold and how it was chosen
- **Results by slice:** per class, per source, per condition (e.g. low light, noise)
- **Calibration:** expected calibration error or reliability plot, if probabilities drive decisions
- **Efficiency:** model size, p50 / p95 latency, hardware, threads
- **Known failure modes:** concrete examples
- **Licence and citation**
